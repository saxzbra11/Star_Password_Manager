# Gestore_di_Password
Un semplice gestore password per gestire tutte quante le tue password! In questa prima release è possibile aggiungere e visualizzare le password salvate.                       ATTENZIONE: Per ora, se si vogliono eliminare le password salvate, basta aprire il file password.txt (che si genera dopo aver salvato una password) ed eliminare l'intera riga
