# Star Password Manager
A simple password manager to manage all your passwords! No ads, no cloud saving, all saved on your PC!

**WARNING**: For now, if you want to delete saved passwords, just open the password.txt file (which is generated after saving a password) and delete the entire line. This also means that the files are not yet encrypted, but this feature will be added in upcoming updates (issue resolved in version 1.1).
