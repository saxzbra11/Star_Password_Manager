
This readme will show you the basic function of the program:

1.Save your passwords
2.Search password by service name
3.Delete password
4.Print a list of services with saved passwords

All of that is combined with a Master Password that, on the first boot of the program, the user will need to insert (don't forget it after you put it, or you lose all of you passwords!)

The saved master password and passwords file can be found in the %APPDATA% folder

I hope you enjoy using this program (my very first project btw :D)
